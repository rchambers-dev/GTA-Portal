## Design principle (summary)

A KSB can be structurally mapped correctly while still having teaching-depth, practice, assessment, or evidence-visibility weaknesses.

A KSB can be substantively taught while having no correct structural Primary.

Programme health must not be reduced to one mapped/unmapped flag.
