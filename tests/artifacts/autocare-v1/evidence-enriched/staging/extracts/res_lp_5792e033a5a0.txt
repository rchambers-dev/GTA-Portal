 Topic
 Targeted Occupational Recap, Gap Teaching and First Aid
 Occupational relevance: The eligible element of this session addresses identified gaps in safety, tools, measurement, technical working and professional behaviours using pathway-relevant examples. Emergency First Aid qualification delivery, formal tests, portfolio assembly and record administration are valuable but are not counted as occupational OTJ in this SOW.
 Lesson aims
 • Use assessment information to address specific occupational learning gaps.
 • Improve understanding or practical performance through coached correction.
 • Complete Emergency First Aid and programme requirements where scheduled.
 By the end, apprentices should be able to
 • Explain or demonstrate improvement in at least one identified occupational gap.
 • Apply tutor feedback and record the change made.
 • Identify a next learning action for the specialist programme.
 • Complete required First Aid/administration separately where applicable.
 How learning will be checked
 • Start: Review prior feedback and identify one occupational gap per apprentice.
 • During: Targeted questioning/practical observation and feedback followed by correction.
 • End: Short learning-impact record showing what improved and next action.
 Simple impact measure
 • Compare the starting-point response with the completed end task.
 • Record: Not yet secure / Developing / Secure.
 • Set one follow-up action only where further support or stretch is needed.
