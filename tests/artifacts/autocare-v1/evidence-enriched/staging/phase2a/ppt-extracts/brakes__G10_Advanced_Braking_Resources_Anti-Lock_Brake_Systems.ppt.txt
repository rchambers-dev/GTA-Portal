===== SLIDE 2 =====
Introduction

The anti-lock brake system (ABS) is an electronic safety system.

The ABS system prevents the brakes from locking the wheels, which would make the vehicle skid.

Next >

It uses information from sensors to control the hydraulic action of the brakes.

===== SLIDE 5 =====
Wheel Speed Sensors and Tone Wheels

The wheel speed sensor measures the speed of rotation of each wheel.

Active(Hall Effect) sensors or inductive sensors may be used depending on the system.Hall sensors need a supply of current to work and create a digital square wave. Inductive sensors don’t need a power supply and create an AC sign wave.

===== SLIDE 6 =====
Inductive Wheel Speed Sensor and Tone Wheel Operation

The frequency and amplitude of the AC signal changes as the speed of the wheel changes.

The tone wheel cuts the magnetic field of the inductive speed sensor.

Next >

This produces an AC voltage at the sensor output, which is sent to the ABS ECU.

===== SLIDE 7 =====
ABS ECU

The ABS ECU tests the system operation and monitors the system during driving.

It has four function areas:

Next >

An input amplifier processes the wheel speed signals

A computer unit calculates the control signals

A power stage drives the solenoid valves

A monitoring circuit detects faults in the ABS system

ABS Warning Lamp

A warning lamp is used to warn the driver if the ABS system is not functioning correctly.

Voltage relays are used to deliver reliable and constant voltage to the electronic components of the system.

The valves are used to control the hydraulic pressure at each brake unit.

Hydraulic System Variations

There are many different types of ABS systems, each designed to use hydraulic control channels and wheel sensor circuits in various combinations.

The hydraulic pressure at each front brake unit is independently controlled by the ABS ECU.

An early front-rear split, three-channel hydraulic system had one rear and two front sensors.

Next >

Common hydraulic pressure is applied to each rear brake unit.

The ABS ECU controls the four stages of an ABS hydraulic cycle:

Next >

Normal – the brake system functions without ABS operation

Isolate – the first phase of the ABS cycle, which isolates pressure

Release – the second phase of the ABS cycle, which releases pressure

Increase – the third phase of the ABS cycle, which increases pressure

===== SLIDE 22 =====
Fail Safe Mode

The brake system must still function if the power to the ABS system fails.

With the power off, the inlet valves are always open and the outlet valves are always closed.

Next >

In this mode, pressurized hydraulic fluid from the master cylinder passes directly to the brake units when the brake pedal is pressed.
