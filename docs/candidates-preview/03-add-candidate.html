What happens next
Starts in Stage 1
Every new candidate begins in Stage 1. Nothing is marked complete automatically.
  • ID verified, with the actual date
  • Maths pass or fail, with the actual date
  • English pass or fail, with the actual date
Responsiveness is set on the record after you save. Review is then due in 1 year if Responsive, or in 3 months if Unresponsive.
